Learn with Yoot — self-hosting

Upload every file in this folder to the root of your website (Cloudflare Pages, Netlify, any static host, or a folder on a school computer served by a small web server).
index.html works on its own, even from a USB stick (double-click). manifest.webmanifest + sw.js + icons make the site installable and fully offline once it has been opened once over https.

Teachers: the cap button (top right) turns on Teacher mode with a 4-digit PIN. #teacher (or the "Teacher dashboard" button) shows every student on this computer, prints a class report, and exports/imports a student as a text code so a child can move to another computer.
Students: "Who is learning today?" keeps one profile per child; the Creative Studio (#studio) is free play with no stars.
All data stays in the browser of each computer (localStorage). Clearing site data deletes it — export first.
